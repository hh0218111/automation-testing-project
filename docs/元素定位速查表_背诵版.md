# Playwright 元素定位速查表（背这个）

---

## 一、定位方式 = 怎么找到页面元素

```
HTML 元素：<input id="username" class="input-box" placeholder="请输入" name="user">

怎么找到它？
    ↓
page.locator("选择器")
```

---

## 二、7 种定位方式（核心）

### 1. 通过 id 定位 —— `#`
```
#id名
```
```python
page.locator("#username")         # 找 id="username" 的元素
page.locator("#login-btn")        # 找 id="login-btn" 的元素
```
**规则：id 前面加 `#`**

---

### 2. 通过 class 定位 —— `.`
```
.class名
```
```python
page.locator(".search-box")       # 找 class="search-box" 的元素
page.locator(".card")             # 找所有 class 包含 card 的元素
cards.count()                     # 返回找到几个
```
**规则：class 前面加 `.`**

---

### 3. 通过文字定位 —— `get_by_text()`
```
get_by_text("页面上的文字")
```
```python
page.get_by_text("取消")          # 找写着"取消"的按钮/元素
page.get_by_text("百度一下")      # 找写着"百度一下"的链接
```
**规则：直接写页面上能看到的文字**

---

### 4. 通过属性定位 —— `[属性="值"]`
```
[属性名="属性值"]
```
```python
page.locator('[placeholder="请输入用户名"]')   # placeholder 属性
page.locator('[data-role="contact"]')          # 自定义 data-* 属性
page.locator('[name="user"]')                  # name 属性
```
**规则：方括号里写 属性="值"**

---

### 5. 嵌套定位 —— 大元素里找小元素
```
"大选择器 小选择器"    （中间空格）
```
```python
page.locator("tr:has-text('张三') .score")
#              ↑ 找到包含"张三"的行    ↑ 在里面找 .score 的元素

page.locator('[data-id="2"]')              # 找 data-id=2 的元素
```
**规则：先锁大范围，再在里面精确定位**

---

### 6. 表单元素操作
```python
# 下拉框
dropdown = page.locator("#city")
dropdown.select_option("shenzhen")   # 选 value="shenzhen" 的选项

# 复选框
page.locator("#hobby-game").check()  # 勾选

# 单选框
page.locator("#gender-male").check() # 选中
```

---

### 7. 动态元素（隐藏/显示）
```python
msg = page.locator("#dynamic-msg")

expect(msg).not_to_be_visible()    # 断言：当前不可见
# ... 点击按钮 ...
expect(msg).to_be_visible()        # 断言：现在可见了
```

---

## 三、选择器速记口诀

| 口诀 | 写法 | 例子 |
|------|------|------|
| id 用 `#` | `#id名` | `#username` |
| class 用 `.` | `.class名` | `.card` |
| 文字直接写 | `get_by_text("")` | `get_by_text("取消")` |
| 属性用方括号 | `[属性="值"]` | `[placeholder="..."]` |
| 嵌套用空格 | `大元素 小元素` | `tr .score` |

---

## 四、必须记住的 3 句话

1. **`page.locator("#id")`** —— 找到元素，返回一个"元素对象"
2. **找到后做什么**：`.fill("内容")` / `.click()` / `.check()` / `.inner_text()`
3. **`expect(元素).to_xxx()`** —— Playwright 自动等待，不用手动 sleep

## 五、自测（盖住答案，口头回答）

**题1**：HTML `<button id="submit-btn" class="btn-primary">提交</button>`，写出 3 种不同定位方式

> 答案：`page.locator("#submit-btn")` / `page.locator(".btn-primary")` / `page.get_by_text("提交")`

**题2**：用户名输入框 `<input placeholder="请输入用户名">`，怎么找到它？

> 答案：`page.locator('[placeholder="请输入用户名"]')`

**题3**：表格第三行里找分数 `<td class="score">95</td>`，怎么写？

> 答案：`page.locator("tr:nth-child(3) .score")` 或 `page.locator("tr:has-text('王五') .score")`

**题4**：下拉框选"深圳"、复选框勾选"游戏"，两句怎么写？

> 答案：`page.locator("#city").select_option("shenzhen")` / `page.locator("#hobby-game").check()`

# 简历项目：WebDriverUniversity 联系表单自动化测试

## 项目概述
基于 Playwright + pytest 的 Web UI 自动化测试项目，采用 POM（Page Object Model）设计模式，实现数据驱动测试。

## 技术栈
- **测试框架**：pytest + Playwright
- **设计模式**：POM（页面对象模型）
- **数据管理**：YAML 数据驱动
- **测试网站**：http://webdriveruniversity.com/Contact-Us/contactus.html

## 项目结构
```
pages/
├── contact_page.py      # 联系页面 POM 类
├── wdu_page.py          # 下拉框/复选框/单选 POM 类
tests/
├── test_contact.py      # 联系表单测试（数据驱动）
├── test_wdu.py          # 下拉框/复选框/单选测试
data/
├── contact_data.yaml    # 测试数据（3组）
```

## 核心功能
1. **表单填写自动化**：自动填写 First Name / Last Name / Email / Comments
2. **多组数据测试**：通过 YAML 文件管理 3 组测试数据，parametrize 自动跑 3 遍
3. **提交验证**：断言提交后页面显示 "Thank You for your Message!"
4. **复用性**：POM 设计模式，页面操作和测试逻辑分离

## 代码亮点
```python
# POM 页面类
class ContactPage:
    def fill_form(self, first, last, email, comment):
        """填写表单"""
        self.first_name.fill(first)
        self.last_name.fill(last)
        ...

# 数据驱动测试
@pytest.mark.parametrize("user", load_data_yaml())
def test_contact_form(contact, user):
    contact.fill_form(user["first"], user["last"], ...)
    contact.submit()
    contact.assert_success()
```

## 测试结果
- 测试用例：3 组
- 通过率：100% (3/3 passed)
- 平均耗时：约 15 秒/组

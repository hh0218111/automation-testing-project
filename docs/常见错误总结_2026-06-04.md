## 错误1：下拉框用 text 不是 value 🔴

**错误**：
```python
dropdown.select_option("深圳")    # ❌ 应该用 value="shenzhen"
```

**原因**：HTML 里 `<option value="shenzhen">深圳</option>`，`select_option()` 只认 value，不认显示文字。

**正确**：
```python
dropdown.select_option("shenzhen")   # ✅ 用 value
```

> **练**：手写 3 遍 `dropdown.select_option("shenzhen")`

## 错误2：check() 不需要传参数 🔴

**错误**：
```python
checkbox.check("coding")    # ❌ check() 是无参方法
```

**正确**：
```python
checkbox = page.locator("input[value='coding']")   # 定位器找到复选框
checkbox.check()                                    # ✅ 无参，直接勾选
```

> **练**：手写 3 遍 `checkbox.check()`（无参！）

## 错误3：断言方法用错了 🔴

| 元素类型 | 正确断言 | 错误用法 |
|---------|---------|---------|
| 下拉框 | `to_have_value("shenzhen")` | ~~to_have_text("深圳")~~ |
| 复选框 | `to_be_checked()` | ~~to_have_value("coding")~~ |
| 输入框 | `to_have_value("张三")` | ✅ 这个对了 |
| 按钮文字 | `to_have_text("登录")` | ✅ 这个对了 |
| 页面标题 | `to_have_title("百度")` | ✅ 这个对了 |

## 错误4：ID 命名和 value 不一致 🟡

**错误**：
```python
# parametrize 传 value
("coding", "gaming", "sport")

# 拼 ID：#hobby-coding → HTML 里是 #hobby-code（少了个 d）
page.locator(f"#hobby-{value}")    # ❌ hobby-coding 不存在
```

**正确（两种方案）**：

方案A：改用属性选择器（推荐，不依赖 id 命名）
```python
page.locator(f"input[value='{hobby_value}']")
```

方案B：改 parametrize 传正确的 id
```python
("hobby-code", "hobby-game", "hobby-sport")
page.locator(f"#{hobby_id}")
```

> **练**：写代码时先看 HTML，确认属性名再写选择器

## 错误5：导入路径写错 🟡

**错误**：
```python
from playwright import Page        # ❌ Page 不在 playwright 里
```

**正确**：
```python
from playwright.sync_api import Page, expect   # ✅
```

> **记**：Playwright 的 Page 和 expect 都在 `playwright.sync_api` 里

## 错误6：属性名和方法名冲突 🔴

**错误**：
```python
class SearchPage:
    def __init__(self, page):
        self.search = page.locator(".search-box")  # 属性

    def search(self, keyword):                      # 方法同名
        self.search.fill(keyword)  # ← Python 找的是属性，当成 Locator 调用，报错
```

**正确**：属性名和方法名必须不同
```python
self.search_input = page.locator(".search-box")  # 属性改名

def search(self, keyword):                         # 方法不变
    self.search_input.fill(keyword)
```

## 错误7：类里裸写 expect() 🔴

**错误**：
```python
class SearchPage:
    def __init__(self):
        self.input = page.locator(".box")
    
    expect(self.input).to_be_visible()  # ❌ 不在方法里！
```

**正确**：断言必须放在方法里
```python
class SearchPage:
    def assert_visible(self):
        expect(self.input).to_be_visible()  # ✅ 在方法里
```

## 错误8：expect() 不传元素 🔴

**错误**：
```python
expect().to_have_value("wuhan")  # ❌ 不知道检查谁
```

**正确**：
```python
dropdown = page.locator("#city")
expect(dropdown).to_have_value("wuhan")  # ✅ 传给 expect
```

---

## 错误9：fill() 返回值赋给变量 🔴

**错误**：
```python
x = page.locator("#id").fill("内容")  # ❌ x = None
```

**正确**：
```python
element = page.locator("#id")    # 先定位
element.fill("内容")              # 再操作（不赋值）
